# rw-wasm (IF9)

`crates/rw-wasm` exports `core_version`, `eval_model`, `apply_and_eval`,
`check_static`, `mesh_glb`, `profile_svg`, and `motor_library` (the built-in
generic motors with their thrust curves, filtered like `rw motor search`; the
page 03 picker) (JSON strings in and out,
`{"ok"}`/`{"error": ApiError}` envelopes; `mesh_glb` returns GLB bytes and
throws). The bodies live in `rw_wasm::api` so native tests run the same code.
`app/packages/rw-wasm` wraps them (`evalModel`, `applyAndEval`, `checkStatic`,
`meshModelGlb`, `profileSvg`, `motorLibrary`; errors throw `RwWasmError`).

- **Equivalence (I4).** `cargo test -p rw-wasm --test native_equiv` compares
  against the `Session`; `pnpm --filter @rw/rw-wasm test` runs the wasm32 build
  in Node against `rocketwright call` on `fixtures/research-vehicle`.
- **Scope.** Motors resolve from the embedded generic curves. Project `lib/`
  files are not in `rw://project/files`, so lib materials and lib motors are
  not visible to the WASM core. `check_static` has no source texts, so its
  `inputs` list only motors; `apply_and_eval` hashes texts like the sidecar
  (files changed by ops are hashed from their patched JSON, preview only).
- **Size.** `make wasm` builds the `wasm` cargo profile (opt-level z, fat LTO,
  abort) and strips names. On wasm32, typed TOML goes through `serde_json::Value`
  (rw-model `source.rs`), and rw-check's field dimension table is generated by
  `build.rs` instead of a runtime `schema_for!`. Result: ~1.83 MB raw, ~0.52 MB
  gzip. The plan budget is 1.5 MB; `scripts/build-wasm.sh` gates at 2.11 MB raw
  (`RW_WASM_MAX_BYTES`; 2.0 MB until M4.4-M4.6 added liquid engines to the
  evaluated model and the `engine_design` chamber preview, 1.963 → 2.069 MB;
  2.1 MB until REV-phys added CD overrides, tank propellant mass, and the
  apogee fallback, 2.0992 → 2.1063 MB).
  The WASM `engine_design` sizes the chamber only (`rw_liquid::design::chamber`)
  so the blowdown and curve code stays out of the module. Reaching 1.5 MB raw needs binaryen `wasm-opt -Oz`
  (not in the toolchain) or hand-written `Deserialize` for the internally tagged
  / flattened model enums (serde `Content` is ~190 KB).
