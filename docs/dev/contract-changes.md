# Contract changes

IF1-IF12 were frozen at M1.5. Any later change to a frozen interface needs a PR
that touches `schema/` and adds one line here: date, interface, change, reason,
and the step that needed it. Update the matching `fixtures/contracts/` payload
in the same PR.

| Interface | Where |
|---|---|
| IF1 source model types | `crates/rw-model/src/types/{source,component,patch,refs}.rs`, `crates/rw-units` (`Qty`, `DimKind`) |
| IF2 `EvaluatedModel` | `crates/rw-model/src/types/eval.rs` |
| IF3 `Geometry` | `crates/rw-geom/src/types.rs` |
| IF4 `ThrustCurve`, `MotorSource` | `crates/rw-motor/src/types.rs` |
| IF5 `AeroModel::eval`, `MassModel::at` | `crates/rw-aero/src/{lib,types}.rs`, `crates/rw-mass/src/{lib,types}.rs` |
| IF6 `SimInput`, `SimResult`, `RunSummary` | `crates/rw-sim/src/{lib,types}.rs` |
| IF7 `CheckReport`, `CheckDelta` | `crates/rw-check/src/{lib,types}.rs` |
| IF8 `Command`, tool I/O, `HistoryStep`, `RunManifest`, `RenderRequest`, `OracleGolden` | `crates/rw-api/src/*.rs`; `schema/oracle-golden.json` |
| IF9 WASM exports | `crates/rw-wasm/src/lib.rs` |
| IF10 WS RPC | `app/packages/contracts/src/rpc.ts` |
| IF11 broker ops | `app/packages/contracts/src/broker.ts` |
| IF12 stand-in fixture format | removed at B17 (was `app/packages/contracts/src/standin.ts`) |

Schema metadata keywords: `x-unit-dimension` (a `DimKind` name), `x-expr`
(field accepts `=` expressions), `x-anchors` (on each component kind; `fin<n>`
means `fin0..fin{count-1}`), `x-ui-group` (on a field; a field without one
inherits its enclosing object's group). On an optional source field the
keywords sit on the non-null branch of its `anyOf`.
